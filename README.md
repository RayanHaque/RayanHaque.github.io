# Rayan Haque — Portfolio starter

A responsive, professional single-page portfolio built with React and Vite, based on the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To build a production bundle:

```bash
npm run build
```

Deploy the `dist` output to Vercel or Netlify, or connect the repository to either service.

## Important edits before publishing

1. Check every statement and project status. Ongoing projects are deliberately identified as such.
2. Add genuine GitHub repository and live-demo URLs to project cards (do **not** fabricate them).
3. Add the verified Scientific Reports article URL/DOI.
4. Replace or remove the public resume (`public/resume.pdf`) if you do not want your phone number exposed online. The supplied resume includes personal contact information. A portfolio-safe PDF with public-only contact details is recommended.
5. Optionally add a LinkedIn URL, professional headshot, and custom domain.
6. Update certifications only if supported by issued credentials.
7. If deploying under a GitHub Pages repository subpath, configure Vite `base` and update the resume link accordingly.

## Notes

The homepage intentionally has no false social or project links. The publication wording reflects the resume rather than separate verification. Website copy is an editorial adaptation of the resume, not an additional claim of work completed.
